# ExcelQueryTool

Windows 桌面端表格快速搜索工具。拖入文件即可流式加载与检索，百万行级工作表依旧可交互；勾选「显示图片」时单元格内的图片与文字同格渲染。

- 版本：版本号单一来源为 `ExcelQueryTool.csproj` 的 `<Version>`，窗体标题与状态栏均跟随
- 技术栈：.NET 10 / WPF（`net10.0-windows7.0`），零第三方依赖（xlsx/CSV/TXT 解析全部自研）
- 数据源：`.xlsx` / `.csv` / `.txt`；旧版 `.xls`（Excel 97-2003）不支持，各入口统一拦截并提示另存为 `.xlsx`

## 主要功能

| 功能 | 说明 |
|---|---|
| 多格式打开 | 打开对话框、拖拽到窗口或表格区域均可；`.xlsx` / `.csv` / `.txt` |
| 列结构自动识别 | xlsx 自动下探两行判定表头行；CSV/TXT 自动识别分隔符、编码与有无表头 |
| 图片同格渲染 | 解析 OOXML 锚定图片与新式单元格内嵌图片；同一单元格多张图按顺序垂直堆叠 |
| 自定义搜索语法 | 排除 `!`、并且 `&`（`+`）、或者 `,`（`;`）、括号分组；列限定 `列=值`（包含）、`列==值`（整格等于）、`列>值` / `列<值` / `列>=值` / `列<=值`（数值比较）；命中词高亮；中英文标点等价 |
| 大文件流式加载 | 单趟扫描 + 有界通道背压，内存占用不随总行数增长 |
| 显示样式统一 | 全表（含表头、图片列文字）统一字号；列级对齐：数字列右对齐、文本列左对齐 |
| 列宽行高可调 | 拖拽调整；同工作表内搜索/切换图片显示时保留，换文件或换表时重置 |

## 使用方式

1. 点击「打开文件」（或直接把文件拖入窗口）
2. 在「选择工作表」下拉框选择工作表（CSV/TXT 以文件名作为唯一工作表）
3. 在「查询内容」输入关键词或搜索语法，回车或点「搜索」
4. 需要看图时勾选「显示图片」

## 搜索语法

| 语法 | 含义 | 示例 |
|---|---|---|
| `关键词` | 任意列包含该文本（忽略大小写） | `气缸` |
| `!关键词` | 排除包含该文本的行 | `!已完成` |
| `&` 或 `+` | 并且 | `气缸&YSC` |
| `,` 或 `;` | 或者 | `螺栓,螺母` |
| `()` | 分组 | `(气缸,滑轨)&YSC` |
| `!` 与 `()` 组合 | 排除整组 | `!(已完成,已关闭)` |
| `列=值` | 指定列包含该文本 | `部门=技术`、`2=技术` |
| `列==值` | 指定列整格等于（两侧去首尾空白，忽略大小写） | `部门==技术部` |
| `列<>值` 或 `列!=值` | 指定列<b>不</b>包含该文本（等价 `!列=值`，命中不高亮） | `仓库<>退货` |
| `列>值` `列<值` `列>=值` `列<=值` | 指定列数值比较（任一侧非数值则该行不匹配） | `数量>100`、`金额<=5000` |

列写法：表头名（精确匹配，忽略大小写）或 1 基列序号；列名写错或序号越界时该条件查无结果，状态栏会提示「⚠ 无此列：××」。列限定可与 `!` / `&` / `,` / `()` 组合，如 `部门=技术,!离职`、`数量>100&!已入库`。

中英文标点等价：`，`＝`,`、`；`＝`;`、`！`＝`!`、`（`＝`(`、`）`＝`)`、`＆`＝`&`、`＋`＝`+`、`＝`＝`=`。

搜索命中的词在单元格内以黄色底色加粗高亮（仅显示层处理，不影响搜索速度）；清空关键词后高亮自动消失。
多个条件可自由嵌套，例如 `(气缸,滑轨)&!已入库`。

## 多格式支持细节

### xlsx

- 表头自动下探：首行若是整表大标题则取第 2 行作表头；窗口固定为 2 行
- 空表头列一律保留并命名 `<列N>`；表头重名追加 `_2` / `_3`
- 日期按单元格 `numFmt` 判定，统一显示为 `yyyy-MM-dd`
- 图片解析两条链路：drawing 锚点（`twoCellAnchor` / `oneCellAnchor` / `absoluteAnchor`）与新式内嵌图片（`vm` → richData → richValueRel → media）
- 同一单元格锚定多张图时全部保留、按包内锚点顺序垂直堆叠（不再丢图）

### CSV / TXT

- **分隔符嗅探**：候选 `,` `\t` `;` `|`，对前 20 行分别试解析，按「多列行占比 × 字段数一致性」打分取最优；全部落空时退化为单列表
- **编码检测**：BOM（UTF-8 / UTF-16）优先；无 BOM 时以 UTF-8 严格试解，失败则按 **GB18030** 解析（中文 Windows 导出的 CSV 常见 GBK）
- **表头判定**：按优先级依次判断——① 首行列名必须齐全（尾随空列除外，出现空列即不是表头）；② 首行不可能是纯数字（整行皆为数字或标准日期则是数据）；③ 列名不会跨行重复出现；④ 数字占比兜底（仅当首两行均 ≥80% 为数字时判数据）。均不成立时默认有表头。可正确识别「代码型数据行」（如 SAP 主数据导出：首行 `ROH / J011012957 / 6002 / 空 / 气缸-XXX / PC`，含空列且代码列跨行重复）
- **字段解析**：遵循 RFC 4180，支持双引号包裹、引号内逗号与换行（多行字段）、`""` 转义
- 列数取全文件最大字段数，短行补空；列命名规则与 xlsx 完全一致
- 文本表无图片概念，勾选「显示图片」对文本表无影响

## 显示样式

- **字号统一**：全表统一 12 号（含表头、图片列文字）。此前普通列继承 DataGrid 默认字号、图片列单独写死 10 号，同一张表里两种字号并存。
- **列级对齐**：数字列右对齐、文本列左对齐，按 Excel「常规」格式的惯例。列是否为数字列由数据区抽样判定（非空值中数字占比 ≥ 80%，样本少于 3 个非空值时不判定），xlsx 与 CSV/TXT 口径一致。
- **不读取 Excel 的字体与对齐设置**：Excel 表格里常因合并单元格、局部加粗、格式刷残留造成同列样式杂乱，按原样渲染会显得忽大忽小；改为统一字号 + 按数据类型对齐，观感稳定。

## 性能

以下为百万行级数据在 Release 下的实测表现：

| 阶段 | 耗时 / 占用 |
|---|---|
| 列元数据判定 | 0.106 s |
| 读解析 + 灌数据（百万行 × 6 列） | 7.5 s → **4.3 s** → **~2.5 s**（尾部并行） |
| 首次打开总耗时（百万行 × 6 列） | 8.9 s → 6.1 s → ~4.5 s → **< 3 s**（轻量行集合消除首绑全表物化） |
| 内存分配峰值 | 约 1451 MB |
| xlsx 行解析吞吐 | 17 万–20 万行 / 秒（串行） |

xlsx 行读取为自写字节级扫描器（在 UTF-8 字节上直接定位标签与属性，仅在落格时解码字符串）。任何不支持的结构自动回退到 `XmlReader` 流式路径，行为完全一致。

**尾部并行**：数据加载采用「头部串行 + 尾部并行」——前 1 万行（布局判定/列占用/数字采样所在）走原串行路径，剩余行按 `<row` 边界切块（SIMD 序列搜索定位边界），多 worker 并行「解析 + 行转换」，merger 按块序过滤、补装图片列（ImageManager 非线程安全）并投递，行序与 Channel 单写者保持不变。`ServerGarbageCollection` 消除多 worker 分配下工作站 GC 的 Gen0 暂停放大。小文件（≤1 万行）完全不走并行路径。行为经「投出行内容 FNV-1a 哈希」逐格比对一致（百万行 1048575 行）。

## 架构

| 组件 | 职责 |
|---|---|
| `MainWindow` | 界面编排、事件处理、计时 |
| `ExcelDataManager` | 工作表枚举、列元数据、流式数据加载 |
| `XlsxSheetReader` | xlsx 行解析（快路径调度、表头下探、日期、列宽） |
| `XlsxByteScanner` | 手写字节级 sheetData 扫描器（UTF-8 直读，实体解码，不支持的结构回退 XmlReader） |
| `TextTableReader` | CSV/TXT 解析（分隔符、编码、表头自动识别，RFC 4180 状态机） |
| `ImageManager` | 图片索引（按文件记忆）+ 位图 LRU 缓存 |
| `XlsxPictureIndex` | OOXML 锚点解析与图片二进制提取 |
| `SearchService` | 搜索语法递归下降解析与求值 |
| `UIStateManager` | 列构建、状态与列宽行高记忆 |
| `RowList` / `RowView` | 轻量行集合（DataGrid 数据源）与按需物化的行视图 |
| `Converters` | `ImageTextPair` → WPF 渲染元素 |
| `XlsxPartPath` | OOXML 包内路径工具 |

## 构建与发布

```bash
# 开发构建
dotnet build -c Debug

# 发布构建（Release 不生成 pdb，产物 4 个文件）
dotnet build -c Release
```

Release 产物位于 `bin/Release/net10.0-windows7.0/`：`ExcelQueryTool.exe`、`ExcelQueryTool.dll`、`ExcelQueryTool.deps.json`、`ExcelQueryTool.runtimeconfig.json`。

## 已知行为边界

- 隐藏行不会被跳过，照常参与加载与搜索
- 不支持旧版 `.xls`（Excel 97-2003，OLE2 复合文档）：打开对话框、拖拽、命令行三个入口统一拦截并提示另存为 `.xlsx`
- CSV/TXT 表头判定为启发式：若首行恰好列名齐全、且各列名与后续行的取值完全不同（罕见），会被判为有表头
- 文本表不支持图片列
